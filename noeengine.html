NoeEngine.

NoeEngine is an experimental game-engine and editor project built for 3D game creation.

Our aim is to explore better creative workflows: editor layouts that can scale from simple to advanced, visual improvements, and more usable development tools. It is a work in progress and these are development directions rather than released features.

NoeEngine / 002AREAS WE ARE EXPLORING
01 / EDITOR

WORK YOUR WAY.

Experimenting with Simple, Mid, and Extreme editor modes so tools can suit the user's level and workflow.

02 / RENDERING

BETTER LOOKING WORLDS.

Exploring lighting, shaders, and rendering changes for immersive 3D experiences.

03 / WORKFLOW

LESS FRICTION.

Refining panels, navigation, and common editing tasks to make daily creation more approachable.

NoeEngine is an evolving engine project with planned Noqeri language integration. Development priorities may change, and no release date or performance guarantees have been announced.
