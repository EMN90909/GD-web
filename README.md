# Acelden Game Studio

A static HTML/CSS/JavaScript recreation inspired by the layout and motion of the user's Wix Studio UmpaUmpa reference, based on a supplied screen recording. It is not an export or pixel-identical copy of the Wix Studio site.

## Pages
- index.html: homepage, projects, tools, studio and Noethric partnership
- team.html: founders
- contact.html: contact form UI (delivery requires configuration)

## Assets
Typography cards replace the original template photography: Noe, Noqeri, NoeEngine. No original Wix template images are included.

## Development
Open index.html in a browser or serve the directory using a static server. Respect reduced motion; no framework dependencies.

## Retired homepage animation (October 2026)

The previous homepage partnership section contained a large black Noethric ink/splash SVG and a scroll-responsive liquid stream system. The stream overlay was generated by `initPage()` in `assets/main.js`, attached to the document body, and drew three SVG paths toward the collaboration card and the "GOT A" heading. The original intent was a one-time splash reveal when the section entered view, but later revisions tied the SVG/brand animation to scroll position, causing rewind behavior, clipping, text overlap, and excess vertical space. The visual was removed from `index.html` and the stream JavaScript removed from `assets/main.js` in favor of a lightweight game-controller SVG in the Noethric partnership section. The historical implementation remains accessible through Git history. No slider or liquid streams are currently used on the homepage.

The game-controller SVG uses an optional gentle CSS float animation and respects `prefers-reduced-motion`. The collaboration section follows immediately after the partnership section without a flow bridge. Footer padding is kept compact.

## Homepage visual cleanup

The hero ticker and IDEA/PLAY/BUILD interlude were removed. The Noethric controller is now stationary and larger. The services preview includes a CSS level-editor scene, and the duplicate collaboration card has been replaced by a single game-themed contact CTA.
